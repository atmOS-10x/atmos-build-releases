# atmOS Build releases

Public downloads for [atmOS Build](https://atmos.build): desktop installers, CLI archives, and the
install scripts. Releases are published automatically from the private source repository; this
repository holds no source code.

Install the latest stable build:

```sh
curl -fsSL https://github.com/atmOS-10x/atmos-build-releases/releases/latest/download/install.sh | sh
```

Nightly builds are the `-nightly.` prereleases on the [Releases](../../releases) page.
